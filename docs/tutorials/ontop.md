# ontop — 窗口置顶

## 用途

让 mpv 窗口始终浮在其他窗口之上,适合:边看视频边记笔记、
代码演示配乐、直播挂机看弹幕。mpv 的置顶是播放器内建行为
(非窗口管理器手动置顶),窗口拖动/全屏切换后依然保持。

## 语法与默认值

```conf
ontop[=<yes|no>]
```

- 默认值:`no`
- 来源:mpv 手册 OPTIONS 章节 ontop 条目
- 本仓库 base.conf:标题栏模板用 `${?ontop==yes:📌}` 变量——
  置顶时窗口标题显示 📌 图标

## 示例

```conf
# 启动即置顶
ontop=yes
```

播放中按快捷键可随时切换(默认未绑定,可在 input.conf 加
`ctrl+t cycle ontop` 之类绑定,或用内置 cycle 脚本)。

## 风险提示

- 置顶窗口会遮挡其他应用,办公/演示时记得切换回来。
- 全屏播放时 ontop 无实际意义(全屏本身独占);退出全屏后恢复
  置顶状态。
- 与"随鼠标出现"的悬浮窗工具(部分 uosc 配置)同时使用体验
  冲突,留意窗口管理器的行为差异。

## 相关选项

- `borderless`:无边框(见教程《borderless — 无边框窗口》)
- `focus-on`:窗口获得焦点的方式
- `title`:标题栏模板中的 `${?ontop==yes:...}` 条件变量
